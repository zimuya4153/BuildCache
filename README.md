# `index`

The build ledger, generated by BuildCache. Do not edit by hand.

* `README.md` — this file
* `<package>/index.json` — every cached version of that package
* `<package>/versions/<version>.json` — one record per build

A record lists the artifacts of each build entry (`id`, package
`configs`, `revision`, `xmake_version`, `toolchain`, plus every
artifact's url/sha256/toolset/buildhash). `revision` is what makes
a fix re-publish old versions: bumping it in `config.json` marks
older records as stale and `discover` queues them again.

`alias_profiles` names the extra consumer toolchains an entry was
published for. Each artifact may then carry `aliases`: manifest
entries that address the very same archive with a build hash
recomputed for another toolchain. Declaring a new profile in a
plugin re-queues the entries that predate it.
